# СПбПУ · Карта развития

Интерактивная карта-граф **«от абитуриента до специалиста»** для Санкт-Петербургского
политехнического университета Петра Великого: институты → направления подготовки →
образовательные дисциплины → карьерные роли → компании-работодатели.

Собрана по открытым источникам университета. Современный тёмный/светлый дизайн,
живая force-симуляция на canvas без внешних зависимостей, панель управления в реальном
времени, поиск, фильтры, карточки узлов и экспорт.

## Запуск

Сайт статический и самодостаточный — достаточно открыть `index.html` в браузере
(работает и по `file://`). Либо поднять локальный сервер:

```bash
python -m http.server 8734
# → http://127.0.0.1:8734/
```

Внешних JS-библиотек нет. Шрифты (Inter / Unbounded) подгружаются с Google Fonts и
корректно деградируют до системных при офлайне.

## Структура

```
index.html          оболочка: шапка, сцена, панель управления, drawer, модалка «О карте»
css/style.css       дизайн-система (тёмная/светлая темы, aurora-фон, скроллбары, адаптив)
js/data.js          датасет графа (автогенерация из открытых источников, см. ниже)
js/graph.js         canvas-движок: симуляция, раскладки, камера, подсветка, экспорт
js/app.js           UI: поиск, фильтры, слайдеры, карточки, темы, горячие клавиши
_research/          исходные HTML + парсер + генератор датасета (провенанс данных)
_test/              headless-тесты (playwright-core + Edge) и скриншоты
```

## Данные и методология

- **Институты (13)** и их сайты — структура СПбПУ (`spbstu.ru/structure/institutes/`).
- **Направления (74: 59 бакалавриат + 10 специалитет + 5 магистратура)**, коды, названия и
  профили — реестр образовательных программ ДООП (`dep.spbstu.ru/edu/`), распарсен автоматически.
- **Расписание** — глубокие ссылки на факультеты `ruz.spbstu.ru` (id факультетов взяты с сайта).
- **Дисциплины (77)** — ориентировочный ключевой состав профиля (типичный учебный план);
  точный состав — в репозитории учебных планов `plan.spbstu.ru`. Помечено в интерфейсе.
- **Карьерные роли (43)** и диапазоны доходов — ориентир по открытым вакансиям, не оферта.
- **Компании (42)**: стратегические партнёры и опорный вуз Росатома отмечены по данным
  `spbstu.ru/partners/strategic-partners/` и новостям университета; остальные — крупные
  работодатели по открытым данным о партнёрствах, базовых кафедрах и найме. Статус каждой
  компании показан в карточке (`partner` / `anchor` / `open`).

Пересборка датасета: `python _research/build_data.py` (читает `_research/programs.json`).

## Управление

- **Клик по узлу** — карточка: дисциплины, профили, роли, компании, ссылки, траектория.
- **Колесо / pinch** — масштаб; **перетаскивание фона** — панорама; **перетаскивание узла** — движение.
- **Панель справа** (всегда видна): раскладка (поток / органика / радиальная), масштаб,
  размер узлов, толщина связей, свечение, подписи, частицы, сетка, тема, отталкивание,
  длина связей, скорость, пауза, слои (дисциплины/роли/компании), фильтр по институтам,
  экспорт PNG / JSON, перемешать / сброс / вписать.
- **Поиск** в шапке (клавиша `/`), **Esc** — закрыть/сбросить, **Space** — пауза,
  **F** — вписать, **R** — перемешать.

## Тесты

```bash
cd _test && node test.js   # требует playwright-core и установленный Edge
```

Проверяет: рендер и отсутствие ошибок, поиск, карточки, клик по canvas, драг, фильтры,
слайдеры, темы, раскладки, экспорт PNG/JSON, стабильность при повторных переключениях,
FPS и мобильную вёрстку (без горизонтального переполнения). Скриншоты — `_test/shots/`.
